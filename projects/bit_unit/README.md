# bit_unit —— 可参数化位操作单元

## 功能
4 种位操作，`sel` 选择：
| sel | 操作 | 例（a=1011_0010, W=8） |
|---|---|---|
| 00 | 全位反转 | 0100_1101 |
| 01 | 高低半区交换 | 0010_1011 |
| 10 | 循环左移 1 位 | 0110_0101 |
| 11 | 低半区复制到高半区 | 0010_0010 |

位宽 `W` 可配置（默认 8，需为偶数）。

## 验证
- **穷举测试**：2^W × 4 组输入，与独立实现的 Python 参考模型逐条比对
- W=8：1024 组，0 失配
- W=16：262144 组，0 失配
- 时序版：流水线一拍对齐，valid 语义验证 1028 周期，0 错误

## 综合结果（Yosys 0.33，通用门）
| 位宽 | 门数 |
|---|---|
| 8 | 42 |
| 16 | 82 |
成本模型：约 5 门/位 + 2 门固定开销
